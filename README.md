# MedQuest

Plataforma estática de estudos médicos em português, sem cadastro ou cobrança. Dados do estudante ficam no LocalStorage do navegador.

## Executar

Abra `index.html` para usar as funções principais. Para habilitar PWA e cache offline, sirva a pasta em localhost (por exemplo `python -m http.server 8000`) ou publique em hospedagem estática HTTPS.

## Publicar gratuitamente

Publique os arquivos desta pasta em GitHub Pages, Cloudflare Pages ou Netlify, usando a pasta raiz como diretório público. Não é necessário backend.

## Dados e backup

Use “Backup dos dados” para exportar ou importar um arquivo JSON. O progresso é local ao navegador/dispositivo.

## Conteúdo médico

Questões são material didático e não substituem diretrizes atualizadas, supervisão acadêmica ou avaliação clínica individual. O banco requer revisão por especialista antes de uso educacional formal.
